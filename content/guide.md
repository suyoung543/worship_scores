# Worship Scores 사용 안내

## Worship Scores 소개

주일마다 바뀌는 콘티, 각자 다르게 필기한 악보, 어디 저장해뒀는지 기억 안 나는 수정본, 모두 하나의 페이지에서 저장하고 쉽게 공유할 수 있습니다.

- 예배마다 곡 순서, 키, 참고 유튜브 링크를 한 번에 정리해요.
- 원본 악보와 세션 각자의 수정본을 따로 저장해서, 내가 올린 최신 악보를 언제든 다시 찾을 수 있어요.
- 같은 곡을 나중에 다시 콘티에 넣으면, 예전에 올려둔 내 수정본이 자동으로 연결돼요.
- PDF든 사진이든 올리면 알아서 보기 좋은 크기로 정리되고, 화면으로 바로 보거나 PDF로 받아 프린트할 수 있어요.

## 이번 예배(예배 콘티)

### 새 예배 만들기

"이번 예배" 탭에서 `+ 새 예배`를 누르고 날짜를 고르면 콘티 탭이 생성됩니다. 콘티 날짜·제목은 화면 위쪽 "날짜/제목 수정"에서 수정할 수 있습니다.

### 곡 추가하기

콘티 화면 아래 "곡 추가"에서 곡을 넣을 수 있습니다.

- 이미 등록된 곡이면: "기존 곡에서 검색"에 제목 일부를 입력하고, 나온 목록에서 곡을 눌러 선택한 뒤 키를 작성하여 추가합니다.
- 등록된 곡이 아니라면: 검색은 비워두고 제목 / 참고 유튜브 링크 / 어느 팀 버전인지 / 키를 직접 입력하세요. 악보 파일도 바로 같이 올릴 수 있어요. "어떤 악보인가요?"에서 콘티에서 받은 원본이면 "원본"을, 이미 수정해둔 악보가 있으면 "인도자 / 메인건반 / 드럼 수정본" 중 해당하는 것을 선택하고 파일을 고르면 됩니다.

콘티에 적은 키와 같은 키의 악보가 있어야 곡 옆에 악보가 연결됩니다. 예를 들어 악보가 E키로만 올라가 있는데 콘티에 F키로 넣으면 "악보 없음"으로 보여요.

### 악보 순서 바꾸기 · 빼기 · 개별 악보 보기

곡마다 `↑` `↓`로 순서를 바꾸고 `빼기`로 콘티에서 뺄 수 있어요 (곡 정보에 저장된 악보 자체는 지워지지 않습니다). 악보는 곡 옆 "보기"로 확인하세요.

악보 보기 화면 아래에서 `PDF로 받기`로 전체를, `N페이지 이미지로 저장`으로 지금 보고 있는 한 장만 이미지(JPG)로 저장할 수 있어요.

### 콘티 전체를 PDF로 받기

**콘티 PDF 받기**
로그인한 내 파트를 기준으로 합칩니다.
내 수정본이 있으면 그것을, 없으면 원본을 자동으로 골라줍니다.
평소에는 이것만 누르면 됩니다.

**원본만**
콘티에서 받은 원본 그대로만 모아서 받고 싶을 때 사용합니다.

**인도자 / 메인건반 / 드럼 수정본**
특정 파트의 악보만 모아서 받고 싶을 때 사용합니다.
다른 파트 악보를 참고하고 싶을 때도 유용합니다.

## 곡 모음

### 원본 악보 올리기

곡 상세 화면에서 키를 찾아 "원본 올리기"를 누르고 파일을 선택합니다.
이미 원본이 있는 키라면 "원본 다시 올리기"로 표시되고, 새로 올리면 기존 원본이 새 파일로 교체됩니다.

### 내 수정본 올리기

같은 화면에서 "내 수정본 올리기"를 누르고 필기·수정한 악보 파일을 올립니다.
내가 올린 수정본은 나만 다시 올릴 수 있고, 다른 파트의 수정본은 보기만 가능합니다.
같은 곡을 나중에 다른 예배에서 다시 쓸 때는 이 화면에 남아있는 내 최신 수정본으로 반영됩니다.

### 다른 키 악보 올리기

곡 상세 화면 아래 "새 키로 악보 올리기"에서 키를 직접 입력하고, "어떤 악보인가요?"에서 원본 또는 파트별 수정본을 고른 뒤 파일을 올리면 새 키가 만들어집니다.
원본 없이 수정본만 먼저 올려도 괜찮아요.
