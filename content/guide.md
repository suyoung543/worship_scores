# Worship Scores 사용 안내

## Worship Scores 소개

주일마다 바뀌는 콘티, 각자 다르게 필기한 악보, 어디 저장해뒀는지 기억 안 나는 수정본, 모두 하나의 페이지에서 저장하고 쉽게 공유할 수 있습니다.

- 예배마다 곡 순서, 키, 참고 유튜브 링크를 한 번에 정리해요.
- 원본 악보와 세션 각자의 수정본을 따로 저장해서, 내가 올린 최신 악보를 언제든 다시 찾을 수 있어요.
- 같은 곡을 나중에 다시 콘티에 넣으면, 예전에 올려둔 내 수정본이 자동으로 연결돼요.
- PDF든 사진이든 올리면 알아서 보기 좋은 크기로 정리되고, 화면으로 바로 보거나 PDF로 받아 프린트할 수 있어요.

## 이번 예배(예배 콘티)

### 새 예배 만들기

"이번 예배" 탭에서 `+ 새 예배`를 누르고 날짜를 고르면 콘티 탭이 생성됩니다. 콘티 날짜·제목은 화면 위쪽 `수정`에서 고칠 수 있습니다.

### 곡 추가하기

콘티 화면 아래 "곡 추가"에서 곡을 넣을 수 있습니다. 맨 위에서 `기존 곡` / `새 곡`을 고르세요.

- 기존 곡: 제목 일부를 검색해서 곡을 누르세요. 그 곡에 올라온 악보 키가 버튼으로 보이니 눌러서 고르면 됩니다. 검색 결과가 없으면 `＋ 새 곡으로 등록`을 눌러 바로 새 곡으로 넘어갈 수 있어요.
- 새 곡: 제목과 참고 유튜브 링크를 입력하세요. 유튜브 팀(예: 마커스워십)은 아래 "버전"에 적으면 됩니다.

그 다음 키와 송폼(선택)을 적고, 악보 파일도 바로 같이 올릴 수 있어요. "어떤 악보인가요?"에서 콘티에서 받은 원본이면 "원본"을, 이미 수정해둔 악보가 있으면 "인도자 / 메인건반 / 드럼 수정본" 중 해당하는 것을 선택하고 파일을 고르면 됩니다.

콘티에 적은 키와 같은 키의 악보가 있어야 곡 옆에 악보가 연결됩니다. 예를 들어 악보가 E키로만 올라가 있는데 콘티에 F키로 넣으면 "악보 없음"으로 보여요.

### 송폼 적기

곡마다 `✎ 송폼 적기`를 눌러 송폼을 적어두세요 (예: I - V1 - V2 - C - B - C - O). 콘티 PDF를 받으면 곡 첫 페이지 위쪽에 송폼이 함께 찍혀 나옵니다.

### 악보 순서 바꾸기 · 빼기 · 개별 악보 보기

곡마다 `↑` `↓`로 순서를 바꾸고 `빼기`로 콘티에서 뺄 수 있어요 (곡 정보에 저장된 악보 자체는 지워지지 않습니다). 악보는 곡 옆 "보기"로 확인하세요.

악보 보기 화면 아래에서 `PDF로 받기`로 전체를, `N페이지 이미지로 저장`으로 지금 보고 있는 한 장만 이미지로 저장할 수 있어요. 이미지는 처음 올린 원본 크기 그대로 받아집니다.

### 콘티 전체를 PDF로 받기

**내 세션 PDF 받기**
로그인한 내 파트를 기준으로 합칩니다.
내 수정본이 있으면 그것을, 없으면 원본을 자동으로 골라줍니다.
평소에는 이것만 누르면 됩니다.

**원본만**
콘티에서 받은 원본 그대로만 모아서 받고 싶을 때 사용합니다.

**인도자 / 메인건반 / 드럼 수정본**
특정 파트의 악보만 모아서 받고 싶을 때 사용합니다.
다른 파트 악보를 참고하고 싶을 때도 유용합니다.

## 곡 모음

### 악보 화면 구성

곡 상세 화면의 악보는 **버전 → 키** 순서로 묶여 있어요. 버전은 편곡이 다른 악보(예: 어노인팅)이고, 따로 이름을 붙이지 않은 악보는 "기본 버전"에 들어갑니다. 버전마다 여러 키의 악보를 둘 수 있습니다.

### 악보 올리기

곡 상세 화면 맨 아래 "악보 올리기"에서 버전(선택) / 키 / 어떤 악보인지(원본 또는 파트별 수정본)를 고르고 파일을 올리세요.

- 버전 칸 아래에 이 곡에 이미 있는 버전이 뜨니 눌러서 고르면 됩니다. 띄어쓰기·대소문자만 다르게 적어도 같은 버전으로 저장돼요.
- 이미 악보가 있는 버전·키·종류로 올리면 새 파일로 교체됩니다.
- 잘못 올린 악보는 그 악보 줄의 `삭제`로 지울 수 있어요 (되돌릴 수 없어요).
- 새 버전은 이름만 새로 적으면 만들어지고, 콘티에 곡을 넣을 때 `E · 어노인팅` 같은 키 버튼으로 골라 쓸 수 있어요.

내 수정본은 내 세션 이름으로 저장되고, 같은 곡을 나중에 다른 예배에서 다시 쓸 때 자동으로 연결됩니다. 원본 없이 수정본만 먼저 올려도 괜찮아요.
