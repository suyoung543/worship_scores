# Worship Scores

예배팀(인도자·메인건반·드럼)이 콘티 순서, 키, 참고 유튜브 링크, 그리고 각자 수정한 악보를
한 곳에 모아 두고 다시 찾아 쓸 수 있게 만든 웹 앱입니다.

- 콘티(예배)마다 곡 순서/키/유튜브 링크를 정리
- 원본 악보와, 세션(인도자/메인건반/드럼)별 수정본을 따로 저장
- 같은 곡을 나중에 다시 쓸 때 예전에 올려둔 내 수정본을 그대로 재사용
- 업로드 시 PDF/이미지를 A4 세로 페이지로 자동 변환 → 보기/다운로드/콘티 PDF 합치기가 전부 같은 형태
- 아이패드에서는 바로 보기, 다른 멤버는 PDF를 받아 프린트

## Supabase / Vercel을 통해 배포

처음 설정하거나 다시 배포할 때 필요한 단계별 가이드는 [docs/SETUP.md](docs/SETUP.md)를 참고하세요.

## 사용 흐름

1. **콘티 만들기**: "이번 예배" 탭 → `+ 새 예배` → 날짜 입력.
2. **곡 추가**: 예배 화면 아래에서 기존 곡을 고르거나 새 곡 제목 + 유튜브 링크 + 키를 입력해 추가.
   - 순서는 각 곡 아래 `↑`/`↓` 버튼으로 조정합니다.
3. **원본 악보 올리기**: 콘티에서 곡 제목을 눌러 "곡 모음" 상세로 이동 → 해당 키의 "원본 올리기"를 펼쳐 PDF/이미지 선택.
   - 콘티에서 받은 콘티 악보(유튜브 링크와 함께 오는 이미지/PDF)를 그대로 올리면 됩니다.
4. **내 수정본 올리기**: 굿노트 등에서 필기한 뒤 내보낸 파일을 같은 화면의 "내 수정본 올리기"에 올립니다.
   - 같은 곡을 나중에 다시 콘티에 넣으면, 예배 화면에 내가 올려둔 최신 수정본이 자동으로 뜹니다.
5. **보기/다운로드**: 각 곡의 "보기" 버튼으로 화면에서 넘겨보거나, "PDF로 받기"로 내려받아 굿노트로 열거나 프린트합니다.
6. **콘티 전체 PDF**: 예배 화면 위쪽 "콘티 PDF 받기" 버튼을 누르면 내 세션 기준(내 수정본 우선, 없으면 원본)으로
   그날 콘티 전체가 한 PDF로 합쳐져서 나옵니다. 프린트하는 멤버에게 이 파일을 공유하면 됩니다.

## 구조 참고

- `supabase/schema.sql` — DB 테이블 및 스토리지 버킷 정의
- `lib/auth.ts`, `middleware.ts` — 공용 비밀번호 + 파트 선택으로 로그인, 서명된 쿠키로 세션 유지
- `lib/db.ts` — 데이터 조회/저장 (모두 `service_role` 키로 서버에서만 실행)
- `lib/convert.ts` — 브라우저에서 업로드 파일을 A4 세로 JPEG 페이지로 변환 (pdf.js + canvas)
- `lib/actions.ts` — 로그인/콘티/곡/업로드 서버 액션
- `lib/pdf.ts`, `app/api/**/pdf/route.ts` — 저장된 페이지 이미지를 PDF로 합쳐서 내려주는 라우트

## 나중에 더할 만한 것들

- 카카오 로그인 등으로 개인별 계정 전환
- 곡 삭제, 콘티 복제(지난주 콘티 복사해서 새로 만들기)
